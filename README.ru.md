# fifine-ht6-linux

**🇬🇧 [English](README.md) · 🇷🇺 Русский**

Управление беспроводной гарнитурой **FIFINE HT6** из Linux: заряд, режим
звука, таймер автоотключения и RGB-подсветка — всё, что делает фирменная
виндовый софт по USB, только без Windows.

Протокол восстановлен статическим разбором приложения производителя
(`api_server.exe` + `hid_ota.dll`) и проверен на живом устройстве.

## Что поддерживается

| Возможность | Статус |
|---|---|
| Уровень заряда и статус | ✅ |
| Режим звука (0/1/2) | ✅ |
| Таймер автоотключения | ✅ |
| Режимы подсветки: always on / cycle / breathing / music rhythm | ✅ |
| Цвет подсветки (RGB) | ✅ |
| Версии прошивок (донгл и гарнитура) | ✅ (читаются из пакета состояния) |
| Эквалайзер | ❌ в устройстве его нет — см. ниже |
| Обновление прошивки (OTA) | ❌ не реализовано |

Проверено на: **VID `3142` / PID `00C3`**, прошивка донгла 1.8, гарнитуры 4.2.
Другие модели FIFINE на таком же донгле (Bolutek/Actions) могут работать —
`./fifine_ht6.py state` покажет, отвечает ли устройство.

### Про эквалайзер

**В гарнитуре нет собственного DSP.** Всё, что SoundLink делает с эквалайзером,
7.1 и пространственным звуком — это APO-драйвер в виндовом аудио-движке, то
есть обработка на стороне компьютера. Портировать нечего: на Linux это делается
через PipeWire или EasyEffects.

Готовая рабочая схема (эквалайзер + виртуальный 7.1 через HRIR) описана в
[docs/AUDIO.md](docs/AUDIO.md).

## Установка

Нужен Python 3 и `python-hidapi`:

```bash
# Arch
sudo pacman -S python-hidapi
# Debian/Ubuntu
sudo apt install python3-hid
# Fedora
sudo dnf install python3-hidapi
```

Дальше:

```bash
git clone https://github.com/th0rrrn/fifine-ht6-linux
cd fifine-ht6-linux
./fifine_ht6.py state
```

Root не нужен — доступ идёт через `/dev/hidraw*`.

## Использование

```bash
./fifine_ht6.py state                    # заряд, режим, цвет, прошивки
./fifine_ht6.py mode 1                   # режим звука 0/1/2
./fifine_ht6.py sleep 30                 # автоотключение в минутах (255 = выкл)
./fifine_ht6.py led breath               # always | cycle | breath | rhythm
./fifine_ht6.py color ff69b4             # цвет подсветки (режим always on)
./fifine_ht6.py color ff69b4 rhythm      # цвет и режим одной командой
./fifine_ht6.py devices                  # список HID-интерфейсов
```

Как библиотека:

```python
import fifine_ht6 as f

dev = f.open_device()
state, _ = f.get_state(dev)
print(state["battery_level"], "%")

f.set_color(dev, 0xFF, 0x69, 0xB4, "rhythm")
dev.close()
```

### Заряд для статус-бара

`tools/fifine-battery` печатает только процент — вставляется в waybar,
polybar, tmux или промпт:

```bash
fifine-battery          # 80%
fifine-battery --json   # {"connected": true, "battery": 80, ...}
fifine-battery --plain  # 80
```

Код возврата 1, если гарнитура выключена или донгл не найден.

## Как устроен протокол

Коротко: устройство общается 64-байтными HID-репортами с report ID `0x55`:

```
55 65 01 00                 прочитать состояние
55 21 01 <mode>             режим звука
55 23 01 <минуты>           таймер сна (255 = выкл)
55 06 00                    прочитать состояние подсветки
```

Запись подсветки требует **транзакции** (`55 0C 01 … 55 05 00 55 01 00`),
иначе донгл молча выбрасывает команду, а чтение продолжает отдавать старое
значение. Полные раскладки пакетов и заметки по реверсу —
[docs/PROTOCOL.md](docs/PROTOCOL.md) (на английском).

`tools/capture.sh` снимает USB-трафик через `tshark`, если захочется добавить
поддержку другой модели.

## Дисклеймер

Это проект совместимости для устройства, которым владеет автор. Протокол
получен наблюдением за работой фирменного софта; код производителя в
репозитории не используется. Прошивка намеренно не реализована — ошибка при
записи превращает донгл в кирпич без пути восстановления.

Проект не связан с FIFINE.
