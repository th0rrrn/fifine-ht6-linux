# FIFINE HT6 — звук на Linux

Итоговая схема после подбора. Всё живёт в графе PipeWire, EasyEffects не
используется (в этой конфигурации у него не создаётся выходной поток).

## Цепочка

```
приложения → FIFINE EQ (10 полос + ширина стерео) → донгл
                    │
                    └─(опционально)→ Virtual Surround 7.1 (HRIR) → донгл
```

## Файлы

| путь | что |
|---|---|
| `~/.config/pipewire/pipewire.conf.d/50-fifine-eq.conf` | эквалайзер + ширина |
| `~/.config/pipewire/pipewire.conf.d/99-virtual-surround.conf` | 7.1 HRIR |
| `~/.local/share/pipewire/hrir_hesuvi/hrir.wav` | импульсный отклик HeSuVi (14 каналов, 44.1 кГц) |
| `~/.local/share/fifine-ht6/audio/*.wav` | тестовые файлы каналов из приложения |

## Команды

```bash
fifine-eq rock        # рок-кривая (текущая)
fifine-eq deep        # тело и низ, сглаженный верх
fifine-eq neutral
fifine-eq preset      # кривая из пресета EasyEffects
fifine-eq show

fifine-width 0.1      # ширина стерео: -1 моно … 0 … +1 широко

fifine-surround on    # добавить виртуальный 7.1 (фильмы, игры)
fifine-surround off   # только EQ (музыка)
fifine-surround test  # прогнать каналы 7.1

fifine-tune next      # перебор вариантов низкой середины 125–500 Гц
```

## Текущие настройки

Кривая (вариант «тело»):

```
   32 Гц  +4.0      1000 Гц  +2.0
   63 Гц  +3.0      2000 Гц  +4.0
  125 Гц  +2.0      4000 Гц  +5.0
  250 Гц  +2.0      8000 Гц  +5.0
  500 Гц  +1.0     16000 Гц  +4.0
```

- ширина стерео: **0.10**
- донгл: **100%** (аппаратная громкость у дешёвых ЦАПов цифровая — на 80%
  теряются биты)
- EQ-звено: **65–70%** (запас под бусты до +5 дБ, иначе клиппинг)
- 7.1: выключен

## Что выяснилось по ходу

1. **Эквалайзер в наушниках отсутствует.** Всё, что делает приложение
   SoundLink, — это APO в виндовом аудио-движке. Команда `55 04` оказалась
   записью цветов подсветки (`55 04 <offset> 00 <RGB>`), а 32-пакетный блок
   при подключении — градиент от текущего цвета к чёрному, 128 шагов.
   DSP в донгле нет, зашить EQ некуда.
2. **Ширина стерео убивает вокал.** Widener работает по mid/side: центр
   (вокал) проваливается, инструментал выигрывает. 0.30 звучало «плоско на
   вокале», 0.10 — приемлемо.
3. **Громкость в двух точках.** Было 80% на EQ и 70% на донгле, суммарно
   −15 дБ — звук воспринимался как «дешёвые динамики». Подняли.
4. **HRIR-свёртка для стерео-музыки вредна.** Она симулирует колонки в
   комнате; для 7.1-контента это плюс, для стерео — минус. Отсюда разделение
   режимов.
5. **EasyEffects в этой схеме не работает**: его sink создаётся, но
   выходного потока нет — он никуда не подключён. Поэтому вся обработка
   перенесена в граф PipeWire.

## Ограничение

Apple Music на iPhone не воспроизводится один-в-один: их пресеты не
документированы, а тракт отличается (другая нормализация, другой рендер).
Кривая выше подобрана на слух и близка, но не идентична.
